BEFORE YOU GO

A few good questions.

Does my code leave my machine?+

Checkpoints stay local. Relayvora has no telemetry. The home screen checks npm for updates at most once a day; disable it with RELAYVORA_NO_UPDATE_CHECK=1. If you explicitly run and confirm sync or send, handoffs go to your own Git remote. Launching an agent uses that agent’s normal provider and data policies.

Which agents can I switch between?+

Claude Code, Codex, and OpenCode have session adapters and direct CLI launching. Relayvora also finds Claude Code and Codex CLIs bundled with supported editor extensions. Other MCP-capable agents can fetch handoffs and save checkpoints through relayvora mcp.

Will switching agents save me money?+

Not always. Small, warm sessions are usually cheaper to continue. The published large-session benchmark reduced tokens and context substantially, but cost was about even. Use Relayvora to keep moving after a limit, switch agents, or resume a large session with work still to do.

Is this actually open source?+

Yes. Relayvora is MIT licensed. The CLI, adapters, benchmark harness, and this website live in the repository. Read the source, open an issue, or contribute an improvement.
