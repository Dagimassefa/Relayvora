GUIDE / SWITCHING AGENTS

Switch between Claude Code, Codex and OpenCode without starting over.

Hit a limit, get stuck, or want a second opinion from another model: the work should move with you. Relayvora hands the task over in any direction between the three agents.

npm install -g relayvoraFree · open source · local-first

Every direction, one command

What the next agent receives

A handoff built within a token budget (4,000 by default): the goal, your latest requests, blockers, test results and changed files always; then failing output, diffs and new files while they fit; anything else as a “fetch this if needed” line. The next agent starts with the brief, not your entire history.

Secrets are redacted before anything is stored, and .env files, keys and binaries are never read.

How the agent is started

Relayvora launches the agent through its documented command line (claude, codex, opencode --prompt) in your terminal and project folder, using the CLI on your PATH or the one bundled with your editor extension. It re-checks the repository just before launching and always asks first.

To continue in an editor panel instead, add --copy and paste, or give the agent the one-line message the summary card prints.

Your own facts, labelled as yours

relayvora handoff --from codex --to claude --goal "Fix leap-year handling" --constraint "Keep the public API" --pending "Handle years divisible by 400" --verify auto

Goals, constraints and steps you pass are labelled [user]. Facts Relayvora verified are [observed]. What the previous agent said about itself stays [agent-reported].

Across machines and teammates

relayvora export and relayvora import move a checkpoint to another computer, optionally with uncommitted changes. relayvora send --to teammate@example.com shares one through a branch in your own Git repository, and they pick it up with relayvora inbox.

Questions

Which agents are supported?+

Claude Code, Codex and OpenCode have session adapters and direct launching. Other MCP-capable agents, such as Cursor, Windsurf and GitHub Copilot, can fetch handoffs and save checkpoints through the Relayvora MCP server.

Will switching agents save money?+

Not always. Small, recently active sessions are usually cheaper to continue. In the repository benchmark, relaying a large session used about 60% fewer input tokens and 71% less context per call, at about the same cost.

What do I need installed?+

Node.js 22.13 or newer and Git 2.31 or newer, on Windows, macOS or Linux. Install with npm install -g relayvora.
